# 隐私政策说明

#### download-manager

适用于基于 Chromium 内核浏览器（Google Chrome、Microsoft Edge 等）的开源下载管理器扩展（Manifest V3）。

**[简体中文](Privacy.md) | [English](Privacy_EN.md)**

**最后更新日期**：2026 年 11 月  
**适用版本**：1.3.0 及以上版本

---

## 1. 数据收集与隐私声明

**download-manager** 高度重视并尊重用户隐私，承诺严格遵循以下原则：

1. **零遥测与零第三方上传**：本扩展**不会收集、跟踪、传输、出售或向开发者及任何第三方共享**您的个人身份信息、网页浏览历史、下载记录列表、下载链接（URL）、文件名称或本地文件内容。所有扩展逻辑均在您的浏览器本地完全运行，不加载任何远程脚本、远程广告或第三方统计 SDK。
2. **仅使用浏览器原生设置同步（可关闭）**：默认情况下，扩展仅利用浏览器内置的 `chrome.storage.sync` 在您登录同一浏览器账号的设备间同步个人外观与交互设置（如主题、图标配色、按钮布局与分类规则等，不包含任何下载历史记录或隐私数据）。您可以随时在扩展「设置」页面中关闭「云同步」，关闭后所有配置将仅保存于当前设备的 `chrome.storage.local` 中。
3. **剪贴板仅限主动单向写入**：仅当您主动点击下载卡片上的「复制下载链接」按钮，或主动右键点击文件名 / 下载链接触发复制时，扩展才会向系统剪贴板写入您所选中的文本；扩展**绝不会读取或监控**您的剪贴板内容。
4. **严格遵循最小必要原则**：本扩展申请的每一项浏览器权限均仅用于实现用户可见的下载管理核心功能（遵循 Chrome Web Store / Microsoft Edge Add-ons 有限使用要求），绝不用于任何与下载管理无关的用途。

## 2. 扩展所使用的浏览器权限说明

本扩展在 `manifest.json`（Manifest V3）中声明并仅使用以下 **9 项权限**：

### 2.1. `downloads`
用于实现核心下载管理能力，包括：
- 查询并展示浏览器下载历史与实时下载进度；
- 发起手动下载、暂停、恢复、取消、删除、重试下载或在本地文件夹中定位文件（`chrome.downloads.show`）；
- 对浏览器标记的潜在危险下载展示确认提示并执行用户选择的保留或舍弃操作（`chrome.downloads.acceptDanger`）；
- 通过 `chrome.downloads.onDeterminingFilename` 根据用户自定义的来源域名与文件扩展名分类规则，自动将文件保存到默认下载目录下的指定子文件夹（完全在本地匹配处理，不离开用户设备）。

### 2.2. `downloads.open`
用于当用户在下载面板中左键点击已完成的下载文件名，或点击系统下载完成通知时，调用 `chrome.downloads.open` 直接使用系统默认程序打开对应已下载的本地文件。

### 2.3. `downloads.shelf`
用于兼容仍采用旧版底部下载栏的 Chromium 内核浏览器：调用 `chrome.downloads.setShelfEnabled(false)` 隐藏开始下载时浏览器底部弹出的默认下载栏，避免与本扩展弹窗界面重复遮挡。

### 2.4. `downloads.ui`
用于在现代 Chrome / Microsoft Edge（Manifest V3）中调用 `chrome.downloads.setUiOptions({ enabled: false })` 抑制浏览器原生右上角下载气泡与默认 UI 弹出，从而以本扩展的统一下载管理面板与动态图标进度提示作为主要交互入口。

### 2.5. `storage`
用于在浏览器本地存储或同步存储中管理扩展配置与临时运行状态：
- **用户偏好持久化**（`chrome.storage.sync` / `chrome.storage.local`）：保存用户选择的浅/深色主题系列、图标配色、弹窗尺寸、顶部/卡片操作栏布局、通知设置及文件分类规则；
- **当前会话状态缓存**（`chrome.storage.session`）：在 Manifest V3 Service Worker 休眠/唤醒周期之间临时缓存在内存中的活跃下载进度投影与待确认下载链接，关闭浏览器后自动清除，不会持久化留存个人浏览记录。

### 2.6. `notifications`
用于根据用户在设置页的开启状态，在下载开始、下载完成或出现安全警告时调用 `chrome.notifications` 展示原生桌面通知，并支持通过通知操作按钮直接打开已下载文件/所在文件夹，或确认由网页右键菜单发起的待启动下载。

### 2.7. `contextMenus`
用于根据用户在设置页中勾选启用的内容类型（链接、图片、音频、视频），在网页右键菜单中创建对应的快捷下载入口（通过 `chrome.contextMenus`）。

### 2.8. `offscreen`
用于在 Manifest V3 架构下按需创建纯本地的离屏文档（`offscreen.html`），仅服务于以下两项 Service Worker 原生环境无法直接执行的本地功能：
1. **下载音效播放（`AUDIO_PLAYBACK`）**：在用户开启下载开始/完成/警告提示音后，于离线文档中播放扩展包内置的本地音频文件；
2. **系统外观侦测（`MATCH_MEDIA`）**：监听操作系统的 `prefers-color-scheme` 浅色/深色模式切换，以便在主题设置为「自动适应」时实时更新浏览器工具栏扩展图标配色。

该离屏文档仅运行扩展自身打包脚本，**不会发起任何网络请求或加载任何外部资源**。

### 2.9. `alarms`
用于在 Manifest V3 Service Worker 生命周期限制下保证长时间或高并发下载时的状态准确性：仅当检测到存在处于进行中（`in_progress`）的下载任务时，以 30 秒为周期调度轻量级对账闹钟（`chrome.alarms`），校对工具栏图标进度与扩展会话中的下载状态；所有活跃下载完成或终止后，立即清除该闹钟，空闲状态下不会在后台唤醒运行。

## 3. 数据留存与用户控制

- 本扩展**不设外部服务器**，不存在任何开发者侧或第三方服务器上的用户数据留存；
- 您可以随时在扩展设置页调整同步方式（关闭云同步以仅保存在本地）、关闭通知/提示音或重置规则；
- 当您在浏览器中停用或卸载本扩展时，扩展在本地及会话中的权限运行立即终止，浏览器扩展存储数据也会按浏览器标准机制清除。
